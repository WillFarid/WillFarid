### 💫 About Me

Cloud Architect/Engineer with hands-on experience delivering cloud infrastructure through project-based work. Knowledgeable in AWS (EC2, VPC, IAM, RDS, S3, Lambda), networking fundamentals (VPC design, subnets, routing, security groups), Infrastructure as Code (Terraform, Ansible), and CI/CD automation using GitHub Actions and Jenkins.

Experienced in provisioning and managing cloud resources using IaC, deploying containerized applications with Docker and Kubernetes (EKS), and supporting Linux-based systems. Strong understanding of cloud security fundamentals, IAM policies, secrets management, DevSecOps practices, and least-privilege access control.

Hands-on with monitoring and observability using CloudWatch, Prometheus, Grafana, and ELK Stack, focusing on system health, logging, and performance visibility. Familiar with configuration management, environment consistency, cost-aware cloud design, and basic high-availability concepts.

Proficient in Git-based workflows, Bash and Python scripting for automation, and collaborating with development teams to support deployments. Experience working with PostgreSQL and MySQL, and continuously building projects around cloud-native and scalable architectures.

Former Systems Administrator in Microsoft environments, with hands-on experience managing and supporting wired and wireless networks, servers, and end-user systems. Knowledgeable in Active Directory (AD-DC), Group Policy (GPO), DNS, DHCP, WDS, WSUS, Microsoft 365 (Office 365), and VMware vSphere/ESXi, with added experience in FortiGate firewall management, patching, backups, and system monitoring. Experienced in hardware and software troubleshooting, user account management, system deployment, and IT inventory management. This enterprise infrastructure background strengthens my cloud work, especially in hybrid environments and on-premises to cloud migrations.
